# Welcome to MyHackMD!

This is a sample markdown file. You can edit it or create new files using the **+** button in the sidebar.

## Features

- **Split-screen editor**: Edit on the left, preview on the right
- **Auto-save**: Your changes are automatically saved after 1 second of inactivity
- **File tree**: Browse all your markdown files in the sidebar
- **Live preview**: See your markdown rendered in real-time

## Markdown Support

This editor supports standard Markdown syntax including:

- Headers (# ## ###)
- **Bold** and *italic* text
- Lists (ordered and unordered)
- Code blocks and inline code
- Links and images
- Blockquotes
- Tables

Happy writing!
